# 2026-05-29 调试记录

> Cartographer 编译安装 + TurtleBot3 环境搭建

---

## 1. Cartographer 编译安装

**现象：** `catkin_make_isolated --install` 产生 `install_isolated/` 目录，和普通 `catkin_make` 的 `devel/` 结构不同。

**原因：** Cartographer 核心库是 plain cmake 包，必须用 `catkin_make_isolated` 或单独 cmake 编译。

**解决：** 按官方 doc 操作：
```bash
wstool merge -t src cartographer_ros.rosinstall
wstool update -t src
rosdep install --from-paths src --ignore-src
src/cartographer/scripts/install_abseil.sh
catkin_make_isolated --install --use-ninja
```

---

## 2. abseil-cpp 依赖问题

**现象：** Ubuntu 20.04 没有 `libabsl-dev` 包，`rosdep install` 失败。

**原因：** ROS Noetic 已 EOL，Ubuntu Focal 源无 abseil。

**解决：** 用 cartographer 自带的 `install_abseil.sh` 从源码编译安装。

---

## 3. 工作区 source 顺序

**现象：** source turtlebot3 工作区后 source cartographer，ROS_PACKAGE_PATH 里 turtlebot3 路径消失了。

**原因：** `install_isolated/setup.bash` 默认不 extend 已有工作区。

**解决：** 加 `--extend`：
```bash
source ~/nav_project/catkin_cartographer/install_isolated/setup.bash --extend
```

**文件：** `~/.bashrc`

---

## 4. Gazebo 启动时卡住

**现象：** `roslaunch gazebo_ros empty_world.launch` 卡住，连不上 `fuel.gazebosim.org`。

**原因：** Gazebo GUI 启动时尝试连接在线模型数据库，被墙。

**解决：** 设置环境变量禁用在线模型库：
```bash
export GAZEBO_MODEL_DATABASE_URI=""
```
并修改 `~/.gazebo/gui.ini` 关闭在线数据库。

**文件：** `~/.bashrc`、`~/.gazebo/gui.ini`

---

## 5. XTDrone 室内地图无法加载

**现象：** 用 Gazebo 加载 `indoor1.world` 时卡住。

**原因：** `indoor1~2.world` 引用了外部模型（`model://cafe` 等），需要联网下载。

**解决：** 改用 `indoor3~7.world`，这些世界文件全部使用内联几何体，无外部依赖。

---

## 6. 话题订阅路径问题

**现象：** 诊断脚本收不到话题数据，但 `rostopic list` 显示话题存在。

**原因：** explore_lite 使用私有 NodeHandle 订阅 `map`（相对路径），解析成 `/explore/map`。

**解决：** 话题名前加 `/` 使用全局路径。

**文件：** `turtlebot3_slam/launch/explore.launch`
